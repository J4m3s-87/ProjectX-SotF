## 🌧️ Realistic Water Collection

Rain catchers now respond to the environment realistically:

- **Winter freezing** — water in your catchers will freeze during winter, just like you'd expect
- **Fire thawing** — place a lit fire (campfire, standing fire) **within 10 meters** of a rain catcher to keep the water liquid through winter
- If the fire goes out, the water eventually freezes again

> **Tip:** Always keep a fire burning near your water supply when winter hits.

## 🥩 Seasonal Meat Drying

Drying racks are supercharged with a seasonal system:

- 🌸 **Spring** — **30x** faster drying · Nearby fire helps
- ☀️ **Summer** — **25x** faster drying · Minimal heat needed
- 🍂 **Autumn** — **15x** faster drying · Nearby fire recommended
- ❄️ **Winter** — **5x** faster drying · Fire required (high heat threshold)

Place a fire source near your drying rack to activate the temperature boost. **Summer is the best season for drying meat.**

## 🏗️ Building & Construction

**Increased Carrying Capacity**
You can carry **more logs, planks, and stones** than in vanilla, with separate configurable limits for each material type (default: 10 each). A small HUD panel shows your current carry count (e.g., "4/10 Logs"). Configurable in Settings → Mods → ProjectX - Builder Stacks.

**Structure Relocator**
Move any built object **without destroying it** — look at a structure (traps, furniture, shelters, decorations), hold the relocation key to pick it up, carry it to a new spot and place it down. Works even on objects vanilla would force you to destroy first.

**Structure Durability**
Server-managed durability multipliers keep your base walls tougher (or more fragile, depending on server settings). This is synced for all players.

**Instant Build**
When enabled by the server admin, structures complete instantly — no waiting for the building animation. Works automatically on the dedicated server for all players.

## 📦 Loot Respawn

- Items you pick up **respawn after a set number of in-game days**
- This includes **ground pickups** (ammo, meds, food, materials), **openable containers** (ammo cases, storage crates), and **breakable containers** (wooden crates, coffins)
- Containers re-appear **closed or intact** and can be opened/broken again for fresh loot
- Timers are configured by the server (e.g., common items every 1 day, rare items every 7 days)
- The world won't feel permanently looted — exploration stays rewarding

**On a Dedicated Server:**
- When **any player** collects loot, it's reported to the server and tracked centrally
- The server manages respawn timers for **all** players — no loot desyncs
- When you join mid-session, the server sends you the current world state so already-looted items stay hidden until their timer expires
- Admin can check tracking status with `/px loot status`, reset all timers with `/px loot reset`, or toggle the feature with `/px loot toggle`

## 🪵 Builder Stacks (Carry More Materials)

Carry more logs, planks, and stones than the vanilla game allows:

- **Logs** — vanilla limit is 2, set yours higher (e.g. 4, 8, 12)
- **Planks** — vanilla limit is 4, set yours higher (e.g. 8, 16)
- **Stones** — vanilla limit is 4, set yours higher (e.g. 8, 16)

How it works:
- Pick up materials normally — the first few stack visually on your shoulder just like in vanilla
- Once your hands are full, extra items are stored in an invisible buffer
- When you place a material, the next one is automatically given back from the buffer
- A HUD panel shows the material icon and your carry count (e.g. "4/8")

To configure:
- Go to **Settings → Mods → Project X → Builder Stacks**
- Type exact numbers in the **Max Log/Plank/Stone Capacity** fields
- **Enable Max Limit** must be ON for the cap to apply (OFF = unlimited)

## ❓ FAQ

**Q: Can I cheat?**
A: No. The Client build has all cheats disabled and the mod menu is locked. Only the server admin can authorize access.

**Q: Will this break my game?**
A: No. The mod only loads when joining modded servers. Remove the DLL from your Mods folder to play vanilla anytime.

**Q: Why are my stack sizes different from what I set locally?**
A: The server overrides local config values so all players have the same experience.

**Q: Why did I get kicked when joining?**
A: The server runs an anti-cheat check. If you have unauthorized mods installed alongside Project X, you'll be kicked. Remove any extra mods from your `Mods/` folder and try again.

**Q: What does the V key do?**
A: It triggers a weapon inspect animation — your character re-equips the held item, replaying the first-equip animation. It's a cosmetic feature.

**Q: Why is crafting so fast?**
A: The server has Faster Crafting enabled. Backpack crafting runs at up to 5x speed by default. This is intentional.

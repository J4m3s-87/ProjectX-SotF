                              1. PLAYER MODULE
================================================================================

PURPOSE:
Provides player quality-of-life features including teleportation of companions.

┌──────────────────────────────────────────────────────────────────────────────┐
│ HOW TO USE                                                                   │
├──────────────────────────────────────────────────────────────────────────────┤
│ 1. Open the Project X menu (default: F1 key)                                │
│ 2. Navigate to the "Player" tab                                             │
│ 3. Toggle cheats on/off:                                                    │
│    • God Mode - Makes you invulnerable to all damage                        │
│    • Infinite Stamina - Never run out of energy                             │
│    • No Hunger - Hunger meter stays full                                    │
│    • No Thirst - Thirst meter stays full                                    │
│    • No Sleep - No tiredness                                                │
│    • Infinite Ammo - Weapons never need reloading                           │
│    • No Fall Damage - Survive any height                                    │
│    • Infinite Logs - Carry unlimited logs                                   │
│                                                                              │
│ UNSTUCK COMPANIONS:                                                          │
│ If Kelvin or Virginia gets stuck somewhere:                                  │
│ 1. Open the Project X menu                                                  │
│ 2. Click "Unstuck Kelvin" or "Unstuck Virginia"                            │
│ 3. They will teleport 2 meters in front of you                             │
└──────────────────────────────────────────────────────────────────────────────┘

CONFIG OPTIONS:
- IsGodMode (bool): Enable invulnerability
- IsInfStamina (bool): Enable infinite stamina
- IsNoHungry (bool): Disable hunger
- IsNoDehydration (bool): Disable dehydration
- IsNoSleep (bool): Disable sleep requirement
- IsInfiniteAmmo (bool): Unlimited ammunition
- IsNoFallDamage (bool): Disable fall damage
- InfiniteLogs (bool): Unlimited log carrying

INTERNAL MECHANICS:
- Kelvin internal name: "Robby", "Robby0", "Robby1"...
- Virginia internal name: "Virginia0", "Virginia1"...
- Uses VailActor.SetPositionAndRotation() for teleportation

                              3. ZIPLINE MODULE
================================================================================

PURPOSE:
Extends zipline construction distance and rope gun firing range.

┌──────────────────────────────────────────────────────────────────────────────┐
│ HOW TO USE                                                                   │
├──────────────────────────────────────────────────────────────────────────────┤
│ This module works AUTOMATICALLY once configured.                             │
│                                                                              │
│ CONFIGURE ZIPLINE DISTANCES:                                                 │
│ 1. Go to Settings → Mods → Project X                                       │
│ 2. Find the "Zipline" section                                               │
│ 3. Set your preferred values:                                               │
│    • MaxZipLineLength: How long the zipline rope can be                     │
│    • MaxRopeBridgeLength: How far rope bridges can span                     │
│    • MaxShootingDistance: How far the rope gun can shoot                    │
│                                                                              │
│ IN-GAME USAGE:                                                               │
│ 1. Equip the Rope Gun                                                       │
│ 2. Aim at a distant anchor point                                            │
│ 3. The extended range lets you shoot much farther than vanilla!             │
│ 4. Build rope bridges spanning valleys that were previously impossible      │
│                                                                              │
│ DEFAULT VALUES:                                                              │
│ • Vanilla zipline length: ~40m                                              │
│ • Modded zipline length: 200m (5x farther!)                                │
└──────────────────────────────────────────────────────────────────────────────┘

CONFIG OPTIONS:
- MaxZipLineLength (float): Maximum zipline rope length
  Default: 200m
  
- MaxRopeBridgeLength (float): Maximum rope bridge construction length
  Default: 200m
  Note: Internally divided by 400 for API (e.g., 200m = 0.5 internal)
  
- MaxShootingDistance (float): Rope gun maximum firing range
  Default: 200m

INTERNAL MECHANICS:
- Modifies RopeGunController._maxRopeLength
- Modifies RopeGunController._maxFiringRange
- Modifies ConstructionSettings.Targeting.MaxRopeBridgeLength
- Uses polling pattern (non-Harmony) for IL2CPP compatibility

│                                                                              │
│ NOTE: In vanilla game, many structures can only be destroyed when moved.    │

                              5. OPEN SESAME MODULE
================================================================================

PURPOSE:
Allows doors to be opened from either side, regardless of lock direction.

┌──────────────────────────────────────────────────────────────────────────────┐
│ HOW TO USE                                                                   │
├──────────────────────────────────────────────────────────────────────────────┤
│ This module works AUTOMATICALLY when enabled.                                │
│                                                                              │
│ ENABLE THE MODULE:                                                           │
│ 1. Go to Settings → Mods → Project X                                       │
│ 2. Enable "OpenSesameEnabled"                                               │
│                                                                              │
│ IN-GAME:                                                                     │
│ 1. Approach any door from EITHER side                                       │
│ 2. The "Open" prompt appears even if you're on the "wrong" side            │
│ 3. Press the interact key to open the door                                  │
│                                                                              │
│ WHY IS THIS USEFUL?                                                          │
│ In vanilla, some doors can only be opened from one side (the "front").     │
│ If you're trapped on the back side, you can't open it.                      │
│ This mod removes that restriction!                                          │
└──────────────────────────────────────────────────────────────────────────────┘

ICON POSITIONS:
- Front: (0, 0, 0.1)
- Behind: (0.1, 0, -0.3)

CONFIG OPTIONS:
- OpenSesameEnabled (bool): Enable/disable door unlocking from behind

INTERNAL MECHANICS:
- Harmony Postfix patch on DoorLock.IsInFront()
- Forces __result = true to allow opening from any side

                              8. WATER COLLECTORS MODULE
================================================================================

PURPOSE:
Prevents rain catchers from freezing in winter when near a fire source.

┌──────────────────────────────────────────────────────────────────────────────┐
│ HOW TO USE                                                                   │
├──────────────────────────────────────────────────────────────────────────────┤
│ This module works AUTOMATICALLY in winter.                                   │
│                                                                              │
│ TO KEEP RAIN CATCHERS UNFROZEN IN WINTER:                                   │
│ 1. Build a Rain Catcher as normal                                           │
│ 2. Build a FIRE nearby (standing fire, campfire, etc.)                      │
│ 3. Keep the fire LIT                                                        │
│ 4. As long as the catcher is within the heat radius, it won't freeze!      │
│                                                                              │
│ CONFIGURING HEAT RADIUS:                                                     │
│ 1. Go to Settings → Mods → Project X                                       │
│ 2. Find "WaterCollectorHeatRadius"                                          │
│ 3. Set the detection distance (default: 10 meters)                          │
│                                                                              │
│ TIPS:                                                                        │
│ • Place multiple catchers around one central fire                           │
│ • Make sure the fire stays burning!                                         │
│ • The effect only matters in Winter (Season 3)                              │
└──────────────────────────────────────────────────────────────────────────────┘

CONFIG OPTIONS:
- WaterCollectorHeatRadius (float): Detection radius for fire sources
  Default: 10m

FIRE DETECTION:
- Searches for objects containing "FireElement" in name
- Checks for active TemperatureModifierVolume component
- Uses Physics.OverlapSphere for detection

INTERNAL MECHANICS:
- Recipe ID 56 = Rain Catcher Prefab
- Injects FireProximityTrigger component into Rain Catcher prefab
- Sets RainCatcher._currentSeason = 1 (Summer) when fire nearby
- Sets RainCatcher._currentSeason = 3 (Winter) when no fire
- Calls RainCatcher.SetFrozen(false/true) accordingly

================================================================================
                             10. SCARY CROSS MODULE
================================================================================

PURPOSE:
Transforms the buildable Cross structure into a functional demon-repelling
effigy that scares away enemies when powered and can even burn them.

┌──────────────────────────────────────────────────────────────────────────────┐
│ HOW TO USE                                                                   │
├──────────────────────────────────────────────────────────────────────────────┤
│ BUILDING A SCARY CROSS:                                                      │
│ 1. Build a Cross structure (found in building menu)                         │
│ 2. Connect it to ELECTRICITY (solar panels + batteries)                     │
│ 3. The cross is now active!                                                 │
│                                                                              │
│ HOW IT WORKS:                                                                │
│ • When powered, the cross has a "demon detection" radius                    │
│ • When demons/cannibals enter the radius, the lights glow brighter          │
│ • The more enemies nearby, the hotter the cross gets                        │
│ • At high heat, the cross CATCHES FIRE and scares/burns enemies            │
│ • CAUTION: The fire damages the cross structure over time!                  │
│                                                                              │
│ EFFECT PROGRESSION:                                                          │
│ 1. Demons approach → Lights start glowing                                   │
│ 2. More demons → Lights get brighter, temperature rises                     │
│ 3. Temperature threshold → Cross catches fire!                              │
│ 4. Fire scares demons away (effigy effect)                                  │
│ 5. Fire can BURN demons within range                                        │
│ 6. Continued fire → Cross takes damage and eventually breaks               │
│                                                                              │
│ TIPS:                                                                        │
│ • Place crosses at your base perimeter for protection                       │
│ • Keep spare materials to rebuild burned crosses                            │
│ • Multiple crosses = better coverage                                        │
│ • Works best with consistent power supply                                   │
└──────────────────────────────────────────────────────────────────────────────┘

MECHANICS:

Temperature System:
- Light intensity rises when demons are in range
- Temperature rises when light intensity exceeds threshold
- At burn threshold, the cross catches fire
- Fire damages the structure over time

Effigy Aura System:
- When powered: Effigy strength scales with temperature
- When unpowered: Uses disabled range/strength values
- Scares demons within range

Demon Burning:
- Burns demons when temperature is high enough
- Range scales with temperature (min to max)
- Triggers ScaryObject burn effect
